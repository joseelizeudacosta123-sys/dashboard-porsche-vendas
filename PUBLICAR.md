# Publicação no GitHub Pages

1. Entre em sua conta no GitHub e crie o repositório público `dashboard-porsche-vendas`.
2. Extraia o ZIP do projeto no computador.
3. Em **Add file → Upload files**, envie os arquivos extraídos. O `index.html` deve ficar na raiz, não dentro de outra pasta. Não envie somente o ZIP.
4. Confirme os arquivos com **Commit changes**.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Selecione a branch **main** e a pasta **/(root)**. Clique em **Save**.
8. Aguarde a conclusão da publicação e copie o endereço mostrado em Pages.
9. Atualize a seção de publicação do README com esse endereço real.
10. Abra o endereço publicado e teste os filtros, inclusive a combinação sem registros e o botão Limpar filtros.

Na entrega do desafio, envie o link do repositório público, não apenas o endereço do painel. O formato comum do painel é `https://SEU_USUARIO.github.io/dashboard-porsche-vendas/`, mas use o endereço confirmado em Settings → Pages.

O HTML também pode ser aberto diretamente no computador. Todos os dados necessários estão embutidos; não exige servidor, instalação ou conexão para funcionar.
